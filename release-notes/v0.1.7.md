- Support PIV F9 certificate import, export and deletion on firmware 3.1.x. Certificate generation and CSR requests remain restricted to ordinary key slots.
- Require explicit confirmation before replacing occupied PIV key slots or certificates, including raw certificate-object imports. Prompts default to no; batch key generation confirms all slots before writing.
- Display existing certificate subjects and SHA-256 fingerprints, warn when F9 changes affect attestation trust, and abort on read errors. Older firmware prompts conservatively when key presence cannot be determined.
